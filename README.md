# Brain Tumor Object Detection Dataset

Dataset Information: A total of 1101 images and corresponding annotation files are available.

Among them:
- Axial (axial image): 371 images
- Coronal (coronal plane): 396 images
- Sagittal (sagittal plane): 334 images

Annotation files are provided in two formats: VOC XML files and YOLO txt files.

The objects annotated include the following:
- Negative: 591
- Positive: 575

The number of annotation boxes is as follows:
- Negative: 591
- Positive: 575

Note that an image may contain multiple objects, so the total number of annotation boxes might be greater than the total number of images.

The complete dataset includes three folders and one txt file:
- all_images folder: Stores the dataset's images, screenshots included.
- All_txt folder and classes.txt: Stores the yolo txt annotation files, with the number of files equal to the number of images. Each annotation file corresponds to each image.
- classes.txt:
- To understand the standard format of the yolo txt file, please search for it yourself on Baidu. In short, the number 0 represents the name of the object at position 0 in the array defined in classes.txt.
- All_xml folder: VOC XML annotation files.
- The quantity and images are the same, with each annotation file corresponding to each image.
- To understand the standard format of the VOC XML file, please search for it yourself on Baidu.
- Both formats of annotation are usable; choose one according to your preference.
